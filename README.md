# 🌟 Phonics & Talk Adventure (兒童自然發音與情境英語大冒險)

一個專為兒童設計的互動式自然發音（Phonics）與情境英語對話（Interactive English Dialogue）網頁小程式。讓小朋友在生動有趣的互動遊戲中，自然而然學會發音規則、字母拼寫與日常英語對話！

## ✨ 主要特色

- 🔤 **拼字大冒險 (Phonics Builder)**：
  - 精選短母音（a, e, i, o, u）三大主題卡關。
  - 支援單字發音、**音素拆解發音 (Phonics Segmentation)** 與字母積木組合反饋。
- 🥣 **發音魔法鍋 (Word Blender)**：
  - 核心字族拼讀法（Onset + Rime），例如 `c` + `at` = `cat`。
  - 直覺理解自然發音拼讀邏輯。
- 🐻 **Toby 英語對話小夥伴 (Magic Talk)**：
  - 內建生活會話情境（問候、喜愛的動物、顏色、心情分享）。
  - 全語音對話發音與正向反饋機制。
- ⭐ **星星收集與激勵系統**：
  - 闖關即時獲得金星獎勵，自動記錄成長里程碑。
- 🚀 **零依賴・跨平台**：
  - 純 HTML5 + CSS3 + Web Speech API + Web Audio API，無需安裝任何後端套件，直接點開即可遊玩。

## 🎮 快速開始

1. 下載本專案：
   ```bash
   git clone https://github.com/zenobialin-ai/kids-phonics-adventure.git
   ```
2. 直接使用任何現代瀏覽器（Google Chrome, Edge, Safari）雙擊打開 `index.html` 即可開始遊玩！
